# Data221 Winter 2026 - Assignment 1

Each python file corresponds to a question on the assignment. Each file runs from one main function but there are some files in which a print statement is needed the values returned.

Each file starts with "DATA221 Assignment 1".

## Question 1.py:

Multiplies integers until a given threshold is reached.

## Question 2.py:

Documents the length and numerical parity of each string in an inputted list. Returns a dictionary which contains the word as a key and the word's length and parity as a nested dictionary value.

## Question 3.py:

Takes a list in which each element is a pair of integers. It iterates through the entire list and returns the calculations of the first integer to the power of the second integer. If either integer is less than zero, the element is skipped ad the program moves to the next element.

## Question 4.py:

Once a list of random numbers between 0 and 1 are created, the function will sort all the values from smallest to largest and check which numbers are smaller than the randomized $x$ value.

## Question 5.py:

Checks if both given radius values are valid numbers that are less than zero. Afterwards, the area of the circles given the radii are calculated. Then, the areas of both circles are compared against each other. The larger one is divided by the smaller one in order to get (as a percentage) the amount of the larger circle's area that the smaller circle would cover.

## Question 6.py:

Analyzes the percentage of numbers in a given list. Returns a dictionary consisting of the numbers as keys and the values as the percentage of numbers in the list that are less than or equal to the number specified.

## Question 7.py:

Receives numerical input for the amount of seconds since midnight. Returns the corresponding hours, minutes, and seconds in addition to returning if the amount of time would be in AM or PM.

## Question 8.py:

By using the pandas library, returns a data frame from the given data. Divides the third column by the first column.
